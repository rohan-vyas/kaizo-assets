# Kaizo brand assets

Public on purpose. Notion page covers can only be set from a publicly
reachable URL, so the banners this repo serves are fetched by Notion when it
renders Kaizo HQ.

Everything here is abstract brand artwork in Kaizo's navy (#16324F) and teal
(#0E7C86). No product screenshots, no customer data, no credentials. Do not
add anything to this repo that you would not put on the website.

## covers/

Seven 2400x800 banners, one family: a diagonal navy-to-teal gradient, two
soft light blooms, and a pair of sweeping arcs, each with a different hue
journey per section so the set reads as designed rather than repeated.
